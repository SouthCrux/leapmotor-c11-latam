# RC1 — community source and documentation milestone

[Castellano](README.md) · [English](README.en.md) · [Русский](README.ru.md) · [简体中文](README.zh-CN.md)

This is the public companion to the RC1 baseline selected after the owner confirmed working map behavior on the central display and instrument cluster. Full regression validation is still pending.

- Pilot: Chinese-market 2024 C11 BEV 580 Premium, used in Uruguay.
- Original cluster-anchor source: 64-pixel upward adjustment.
- Original, build-specific coordinate-validation assembly fragment and technical explanation.
- Four-language explanation of the initiating owner's experience, current limits and long-term LATAM goals.
- All-country regional roadmap, including map-assisted navigation as a future objective.
- Earlier development screenshots with geographic and identifying content removed locally.
- Local helper compilation verified; public-tree checks passed.

Traffic, speed-camera and later home-arrival extensions are not active in this RC1 baseline. No ADAS/NOA or autonomous-driving capability is delivered.

**No manufacturer binaries, complete modified APK, firmware, map packages, VIN, credentials or personal travel data are included. This release is not a complete RC1 installer.** Its public Git history is independent of the private recovery copy.
